# Evaluation record: Title — YYYY-MM-DD

Historical evidence appendix to [the evaluation plan](../evaluations.md).
Record the plan phase, exact versions, and whether review was scripted, assistant,
or independent human review. Results qualify only the recorded trial.

## Method and boundaries

Frozen inputs, provider/model, source revision, prompt/runtime identities, budgets,
selection method, and expected outcomes defined before execution.

## Results and evidence

Report every attempt, including failed runs. Separate runtime completion, exact
grounding, semantic usefulness, and independent acceptance. Link optional local
run artifacts, but make this report understandable without them.

## Limitations and next step

Known errors, uncertainty, repeat variation, and the next bounded experiment.
Do not silently relabel old outputs or treat software tests as task accuracy.
